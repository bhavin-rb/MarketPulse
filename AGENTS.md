# Stock Forecasting Dashboard App

## Description
This app is a **machine learning–powered stock forecasting dashboard** built on top of the existing repository:  
👉 [ml-stock-forecasting](https://github.com/bhavin-rb/ml-stock-forecasting/tree/main)

The purpose of the app is to provide users with:
- **Interactive stock analysis** using historical data from Yahoo Finance.
- **7 day forecasts** generated by the ML models already implemented in the repository (static vs dynamic regression, portfolio forecasting, and extensions like ARIMA/GARCH).
- A **visual dashboard** that combines vivid charts (line, bar, pie) with confidence intervals, allowing users to explore single stocks or build portfolios.
- Flexible date handling: either user entered start date or automatic use of the current system date to display the last 3 months plus forecast.

This app transforms the research notebooks into a **customer friendly application**, making forecasting results accessible, interactive, and visually engaging.

## Goals
- Allow users to enter one or more stock tickers (e.g., AAPL, MSFT, NVDA).
- Fetch historical data (last 3 months) from Yahoo Finance.
- Generate a **7‑day forecast** using the ML models from the repo.
- Display results in a **dashboard** with vivid visualizations:
  - Line chart → historical + forecast overlay.
  - Bar chart → daily changes.
  - Pie chart → portfolio weights.
  - Confidence shading → forecast uncertainty.
- Provide two date options:
  - User enters start date.
  - App auto‑detects current system date.
- Support both **single stock** and **portfolio forecasts**.
- Use distinct, subtle colors for each year/forecast period.

---

## Architecture Principles
- Use a **hybrid approach**: Python backend (Flask or FastAPI) + React/Next.js frontend.
- Backend should handle:
  - Fetching data from Yahoo Finance.
  - Running forecasting models from the repo.
  - Returning results in a structured format (JSON or equivalent).
- Frontend should handle:
  - User input for tickers and dates.
  - Dynamic chart rendering with vivid visuals.
  - Portfolio aggregation when multiple tickers are selected.
- The agent is free to decide the exact API design, routing, and data structures, as long as the above principles are met.

---

## Visual Design
- **Line chart** → Indigo for history, Emerald for forecast.
- **Bar chart** → Blue for gains, Red for losses.
- **Pie chart** → Distinct colors per stock.
- **Confidence shading** → Transparent band around forecast line.

---

## Ticker Resolution
- Users may enter either ticker symbols (AAPL, MSFT) or company names (Apple, Microsoft).
- The app should resolve company names to tickers using either:
  - A small dictionary of common mappings, or
  - Yahoo Finance’s search functionality.
- For portfolios, multiple tickers should be fetched and combined into a single forecast dataset.
